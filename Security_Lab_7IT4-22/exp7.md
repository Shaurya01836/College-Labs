# Experiment-7

## Objective

Demonstrate intrusion detection system using any tool (Snort or any other software).

## Program

### A. Configure and Use Snort IDS on Windows

Steps to configure Snort on Windows machine and how to use it for detection of attacks.

### B. Steps

#### 1. Download Snort

Download Snort from:

`http://www.snort.org/`

#### 2. Download Snort Rules

Also download Rules from the same website. You need to sign up to get rules for registered users.

#### 3. Install Snort

Click on the `Snort_(version-number)_Installer.exe` file to install it.

By default, it will install Snort in:

```text
C:\Snort
```

#### 4. Extract the Rules File

Extract the downloaded Rules file:

```text
snortrules-snapshot-(number).tar.gz
```

#### 5. Copy Rules

Copy all files from the `rules` directory of the extracted folder and paste them into:

```text
C:\Snort\rules
```

#### 6. Copy `snort.conf`

Copy the `snort.conf` file from the `etc` directory of the extracted folder and paste it into:

```text
C:\Snort\etc
```

Overwrite the existing file if there is one.

#### 7. Open Command Prompt

Open Command Prompt (`cmd.exe`) and navigate to:

```text
C:\Snort\bin
```

#### 8. Execute Snort in Sniffer Mode

To execute Snort in sniffer mode, use:

```bash
snort -dev -i 2
```

Where:

- `-i` indicates the interface number.
- `-dev` is used to run Snort to capture packets.

To check the interface list:

```bash
snort -W
```

#### 9. Configure Snort in IDS Mode

To execute Snort in IDS mode, configure the `snort.conf` file according to your network environment.

#### 10. Set `HOME_NET`

Set up the network address that you want to protect in the `snort.conf` file.

Look for `HOME_NET` and add your IP address:

```text
var HOME_NET 10.1.1.17/8
```

#### 11. Configure Additional Addresses

You can also set addresses or `DNS_SERVERS`, if you have any. Otherwise, go to the next step.

#### 12. Set `RULE_PATH`

Change the `RULE_PATH` variable with the path of the rules directory:

```text
var RULE_PATH c:\snort\rules
```

#### 13. Configure Library Paths

Change the path of all libraries with the name and path on your system, or change the path of the `snort_dynamicpreprocessor` variable.

Example:

```text
C:\Snort\lib\snort_dynamiccpreprocessor\sf_dcerpc.dll
```

You need to do this for all library files in the `C:\Snort\lib` directory.

The old path might be something like:

```text
/usr/local/lib/...
```

Replace that path with your system path.

#### 14. Configure `dynamicengine`

Change the path of the `dynamicengine` variable value in the `snort.conf` file with the path on your system.

Example:

```text
dynamicengine C:\Snort\lib\snort_dynamicengine\sf_engine.dll
```

#### 15. Add Configuration File Paths

Add the complete paths for the `classification.config` and `reference.config` files:

```text
include c:\snort\etc\classification.config
include c:\snort\etc\reference.config
```

#### 16. Enable ICMP Rules

Remove the comment from the line to allow ICMP rules, if it is already commented:

```text
include $RULE_PATH/icmp.rules
```

#### 17. Enable ICMP-Info Rules

Similarly, remove the comment from the ICMP-info rules line, if it is already commented:

```text
include $RULE_PATH/icmp-info.rules
```

#### 18. Configure Alert Log

To add a log file to store alerts generated by Snort, search for `"output log"` and add:

```text
output alert_fast: snort-alerts.ids
```

#### 19. Configure White/Black Lists

Comment the following whitelist and blacklist lines:

```text
$WHITE_LIST_PATH/white_list.rules
$BLACK_LIST_PATH/black_list.rules
```

Also ensure that you change the line above `$WHITE_LIST_PATH` as required.

Change:

```text
nested_ip inner , \
```

to:

```text
nested_ip inner #, \
```

#### 20. Comment Normalization Preprocessors

Comment the following lines:

```text
#preprocessor normalize_ip4
#preprocessor normalize_tcp: ips ecn stream
#preprocessor normalize_icmp4
#preprocessor normalize_ip6
#preprocessor normalize_icmp6
```

#### 21. Save the Configuration

Save the `snort.conf` file and close it.

#### 22. Create the Alert Log File

Go to:

```text
C:\Snort\log
```

Create a file named:

```text
snort-alerts.ids
```

#### 23. Start Snort in IDS Mode

Run:

```bash
snort -c c:\snort\etc\snort.conf -l c:\snort\log -i 2
```

The above command will generate a log file that will not be readable without using a tool.

To read it:

```text
C:\Snort\Bin\> snort -r ..\log\log-filename
```

To generate log files in ASCII mode while running Snort in IDS mode:

```bash
snort -A console -i2 -c c:\Snort\etc\snort.conf -l c:\Snort\log -K ascii
```

#### 24. Test Snort

Scan the computer running Snort from another computer using PING or launch an attack.

Then check the `snort-alerts.ids` file for the log.
